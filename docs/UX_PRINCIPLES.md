# CASE — UX principles

- Le monde réel est l'écran principal.
- Une action dominante par écran.
- Pendant un déplacement, afficher le strict minimum: direction, distance, sécurité.
- Demander explicitement au joueur de ranger le téléphone.
- Utiliser vibration/haptique pour rappeler le joueur.
- Rouge uniquement pour menace, urgence, contradiction ou progression critique.
- Le carnet est un outil de réflexion, pas un inventaire décoratif.
- L'interrogatoire est voice-first; transcript et preuves restent secondaires.
- Les preuves du monde réel doivent réapparaître plus tard dans la narration.
- Aucun langage laissant croire que le joueur est un vrai policier.
- Toujours prévoir un fallback si un lieu ou challenge devient impraticable.

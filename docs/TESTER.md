# Guide testeur — 23:17

Le testeur ne doit pas connaître la solution avant sa première vraie partie.

À noter après chaque session :
- moment où l'immersion a commencé ;
- moment où l'envie de regarder le téléphone a remplacé l'observation du monde ;
- énigme comprise sans aide ou non ;
- déplacement jugé naturel ou artificiel ;
- suspect cru à chaque chapitre ;
- contradiction découverte spontanément ou non ;
- moment le plus mémorable ;
- envie de lancer l'affaire suivante sur 10.

Bloquant : mission impossible, lieu inaccessible, vérité contradictoire, progression coincée, permission native empêchant de continuer.

## Tester sur téléphone
1. `npm install` puis `npx expo start`, scanner le QR code avec Expo Go.
2. Accepter la localisation : l'écran « Terrain » affiche « AUTOUR DE TOI · GPS + OPENSTREETMAP » et de vrais noms de lieux.
3. Pour tester sans marcher : « Tester sans bouger : environnement simulé », ou « Je suis dans la zone » sur l'écran « Range ton téléphone ».
4. Fermer l'app en pleine partie puis la rouvrir : « Reprendre l'enquête ».
5. En fin de chapitre I, « Mode test · ouvrir le chapitre II maintenant » évite d'attendre 07:42.
6. Chaque écran porte un repère en bas à gauche (« 12 · Interrogatoire Léo ») : le citer dans les retours.
